# 📱 AI Content Analyzer (Android App)

An AI-powered Android application that analyzes both images and text to detect whether the content is AI-generated or human-generated.

---

## 🚀 Features

- 🖼️ Image Analysis  
  Detects whether an image is AI-generated using:
  - Metadata analysis  
  - Pattern inconsistencies  
  - Visual anomalies  

- 📝 Text Analysis  
  Analyzes text to classify it as AI-generated or human-written  

- 📊 Confidence Score  
  Displays probability (e.g., 70% Human Generated)

- ⚡ Real-time Processing  
  Fast and responsive results

---

## 🛠️ Tech Stack

- **Language:** Kotlin  
- **Architecture:** MVVM  
- **UI:** XML / Android Views  
- **Tools:** Android Studio  
- **Other Concepts:**  
  - Metadata extraction  
  - Pattern detection logic  
  - Basic AI-based evaluation
